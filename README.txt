OpenReactive - 3D Scene Processing and Projection System
========================================================

A powerful OpenGL-esque system for processing 3D objects and scenes with
projection capabilities to JavaScript, CSS, and HTML.

Includes OpenRakix (OpenRX) - the eternal library for projecting 3D scenes
onto operating system wallpapers.

Installation:
    pip install -e .

Usage:
    openreactive --help
    openrx --help
